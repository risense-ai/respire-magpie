# First-use installation guidance: 0.3.9

The plugin page previously said to prepare an existing Runtime, but did not tell a new user where to install the Respire application. The settings page now shows an always-visible first-use section before the form: CLI GitHub/npm/Releases links, installation command, Runtime guide, status check and the order of configuration. The usage section and both upstream/community READMEs explain that this is an integration and the CLI supplies the library/Runtime. No engine installation, account action, automatic service start or connection checker was added.

The command originally copied from the CLI repository/npm guide was subsequently identified by the user as obsolete. It is withdrawn; current installation uses rsrs-cli (https://www.npmjs.com/package/rsrs-cli). 0.3.9 is retained as a failed onboarding candidate and must not be recommended for its installation instructions. Hook, worker and readback code is unchanged from [0.3.8's scoped real acceptance](NPM-LIVE-0.3.8.md). This revision's UI/distribution checks are pending at the source checkpoint; do not equate source text with an installed user's page.
